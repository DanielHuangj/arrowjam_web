> **版本**：v0.1  
> **日期**：2026-06-15  
> **状态**：游戏客户端已实现（测试/辅助向）  
> **关联文档**：[arrow_jaw_开发需求文档.md](arrow_jaw_开发需求文档.md) · [Arrow玩法规则详解.md](Arrow玩法规则详解.md)

---

## 1. 概述

本文档描述游戏关卡内 HUD 上的三项**辅助道具**功能。当前版本以**测试与体验辅助**为目的，在 `code/client` 游戏客户端中常驻显示，不消耗次数、不写入关卡 JSON。

三项道具与核心玩法的区别：

| 维度 | 正常点击发射 | 道具消除 |
|------|-------------|----------|
| 是否遵守路径阻挡 | 是 | **湮灭类道具否**；自动消除仍遵守 |
| 是否播放飞出动画 | 飞出 / 弹回 | 湮灭淡出 |
| 是否计入误操作 | 阻挡点击会计入 | 湮灭不计入误操作 |

---

## 2. 道具一览

| 道具名称 | HUD 按钮 | 作用摘要 | 每次影响箭数 |
|----------|----------|----------|--------------|
| 自动消除 | `自动消除` | 自动选取一条**当前无阻挡、可立即出界**的箭并发射 | 1 |
| 随机消除 | `随机消除` | 随机消除最多 3 条**可见且符合条件**的箭（无视阻挡） | ≤ 3 |
| 指定消除 | `指定消除` | 进入点选模式，玩家指定消除 1 条符合条件的箭（无视阻挡） | 1 |

---

## 3. 自动消除

### 3.1 功能说明

- 点击按钮后，系统自动在关卡中查找一条**可立即消除**的箭头，并执行与玩家手动点击该箭**完全相同**的发射逻辑（`tryLaunch`）。
- 若路径畅通，箭按正常规则飞出棋盘；若逻辑上不应发射，则不会选取该箭（仅从无阻挡候选中选取）。

### 3.2 候选条件

与 `getLaunchableIds()` 一致，须同时满足：

- 关卡处于 `playing` 阶段
- 箭头当前**可见且可操作**（顶层或已揭示子区域内）
- 未被幕布遮盖
- 捆绑组须整组可出界（捆绑机制照旧）
- 模拟路径检测 `simulateCanExit`（或捆绑组 `canLaunchGroup`）为 **true**

### 3.3 选取策略

- 从候选集合中取**第一条**（实现为 `launchable[0]`，非随机）。
- 无候选时按钮**禁用**，点击无效。

### 3.4 动画与副作用

- 使用标准**发射动画**（`exit` / `bump`），**不是**湮灭效果。
- 飞出后正常触发：钥匙奖励、管道扣血、子区域揭示、消除痕迹等既有逻辑。

---

## 4. 随机消除

### 4.1 功能说明

- 点击按钮后，从符合条件的箭头中**随机**抽取最多 **3** 条，直接消除。
- **无视路径阻挡**，不要求箭能飞出棋盘。
- 使用**湮灭动画**后从棋盘移除。

### 4.2 候选条件（`canVanishArrow`）

须同时满足：

| 条件 | 说明 |
|------|------|
| 可见 | 顶层或**已开放**子区域内的 kind 1 箭 |
| 非幕布遮盖 | `curtainManager.isArrowHidden` 为 false |
| 非捆绑箭 | 不属于 kind 8 捆绑组（`bundleManager.getGroupForArrow` 为空） |
| 无钥匙 | 箭身占用格上无 kind 11 钥匙（`arrowHasKey` 为 false） |

**不适用**于：

- 未开放子区域内的箭
- 幕布下的箭
- 捆绑组内任意成员箭
- 格上附着钥匙的箭

### 4.3 数量规则

- 默认一次消除 **3** 条（常量 `RANDOM_VANISH_COUNT = 3`）。
- 若候选不足 3 条，则消除**全部**候选。
- 候选为 0 时按钮**禁用**。

### 4.4 选取策略

- 对候选列表**随机打乱**（Fisher–Yates shuffle）后取前 N 条。
- 同一次操作中多条箭**并行**播放湮灭动画。

### 4.5 副作用

- 消除格记录**消除痕迹**（淡色点），与正常飞出消除一致。
- 若箭上带钥匙，**不会**被随机消除选中，故不触发幕布钥匙奖励。
- 不触发管道穿行扣血（未走飞出路径）。

---

## 5. 指定消除

### 5.1 功能说明

- 点击「指定消除」进入**点选模式**；再次点击该按钮退出。
- 点选模式下，玩家点击棋盘上一条符合条件的箭，将其消除。
- **无视路径阻挡**；使用与随机消除相同的**湮灭动画**。

### 5.2 候选条件

与随机消除**完全相同**（见 §4.2）。

### 5.3 交互与 UI

| 状态 | 表现 |
|------|------|
| 未进入点选模式 | 按钮常态；无可选箭时禁用 |
| 已进入点选模式 | 按钮高亮（`active`）；棋盘与 Canvas 为十字准星光标 |
| 悬停可消除箭 | 白色十字准星 |
| 悬停不可消除物件 | **红色十字准星**（提醒） |
| 悬停空格 | 白色十字准星 |
| 点击可消除箭 | 播放湮灭并消除；**保持**点选模式，可连续指定 |
| 点击不可消除格 | 无效果 |
| 动画中 / 非 playing | 自动退出点选模式 |

**红色准星**适用于：捆绑箭、带钥匙箭、幕布格、角块、管道、捆绑线、钥匙等非可指定目标。

### 5.4 与点击发射的优先级

- 点选模式开启时，棋盘点击走 `tryTargetVanishAtCell`，**不**触发正常 `tryLaunch`。
- 点击「随机消除」会**退出**点选模式后再执行随机消除。

---

## 6. 湮灭动画（随机消除 / 指定消除共用）

### 6.1 动画模式

- `LaunchAnimation.mode = "vanish"`
- 步进帧数：`VANISH_ANIM_STEPS = 12`（约 0.48s，与游戏 `ANIM_INTERVAL_MS = 40` 配合）

### 6.2 视觉效果

- 箭身**缩小**、**淡出**
- 各占用格心出现**白色/箭色光晕**扩散
- 动画结束后从 `arrows` 移除，并写入消除痕迹

### 6.3 与发射动画的区别

| 项目 | 发射（exit/bump） | 湮灭（vanish） |
|------|-------------------|----------------|
| 箭移动 | 沿方向步进 | 原地特效 |
| 阻挡检测 | 有 | 无 |
| 误操作计数 | bump 时 +1 | 无 |
| 管道穿行 | 有 | 无 |

---

## 7. 可见性判定（共用）

「当前可见的 kind 1 箭」在代码中由 `getActiveArrows()` 统一判定：

1. **幕布**：箭身任一格被激活幕布遮盖 → 不可见  
2. **子区域**：箭在 kind 12 子区域内时，仅当 `zoneManager.isArrowActive` 为 true（区域已揭示）→ 可见  
3. **顶层**：`zoneId == null` 的箭在幕布未遮盖时 → 可见  

管道内穿行的箭在发射动画中会暂时隐藏，与道具候选无关（道具仅在 `playing` 且无动画时使用）。

## 8. 按钮可用性汇总

| 按钮 | 启用条件 |
|------|----------|
| 自动消除 | `playing` 且 `getLaunchableIds().size > 0` |
| 随机消除 | `playing` 且 `getRandomVanishCandidates().length > 0` |
| 指定消除 | `playing` 且（已在点选模式 **或** `getTargetVanishCandidates().length > 0`） |

## 11. P5 新机制交互（kind 5 / kind 13）

| 道具 | 冻结箭（kind 13） | 定时炸弹（kind 5） |
|------|-------------------|-------------------|
| 自动消除 | 不可选取冻结宿主 | — |
| 随机/指定湮灭 | **不可**湮灭冻结宿主 | 宿主湮灭则炸弹移除 |
| 正常飞出消除宿主 | 不直接减冻结血（邻接规则另计） | 炸弹移除 |

消除事件仍会触发 kind 2 翻转与 kind 7 移动墙（见 [arrow_jaw_新机制开发需求文档.md](arrow_jaw_新机制开发需求文档.md)）。

## 12. 后续扩展（未实现）

以下为潜在产品化方向，**当前版本未做**：

- 道具次数、冷却、关卡内掉落与消耗
- 道具数据写入关卡 JSON 或 manifest
- 随机消除 / 指定消除触发钥匙、捆绑联动等副作用的策略配置
- 音效与更复杂粒子

如需将道具从「测试辅助」改为「正式关卡机制」，须在本需求基础上补充：道具配置 schema、UI 数量展示、胜负统计与编辑器支持。
