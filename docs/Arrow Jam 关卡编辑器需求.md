# Arrow Jam 关卡编辑器需求

## 一、项目概述

### 1.1 项目背景

Arrow Jam 是一款基于网格棋盘的箭矢消除类手游，目前关卡数据采用 JSON 文件（`arrowJam-main-level-{N}.json`）进行手工编辑。手工编辑存在以下痛点：

- **编辑效率低**：复杂的矩形区域（kind: 6 幕布、kind: 12 子区域）涉及数十甚至上百个坐标点，手写极易出错。
- **可视化差**：无法直观看到箭的折线走向、反射角块的折射方向、管道的出入口等。
- **版本管理困难**：JSON 文件缺乏可视化的差异对比。
- **学习成本高**：新关卡设计师需要熟记所有 kind 类型的字段语义。

### 1.2 项目目标

开发一款 Arrow 关卡可视化编辑器（Arrow Jam Level Editor），实现关卡数据的"所见即所得"编辑，核心能力为：

- **可视化**：所有物件在棋盘网格上以图形化方式呈现。
- **结构化编辑**：通过属性面板配置参数，无需直接书写 JSON。
- **保存 / 读取 / 修改**：完整覆盖关卡配置的全生命周期管理。

### 1.3 术语约定

| 术语 | 含义 |
|------|------|
| 棋盘 | 由 width × height 网格组成的关卡画布 |
| 物件 | 关卡中可交互的元素（箭、管道、角块等） |
| 坐标 | (x, y)，x 为列（向右增大），y 为行（向下增大） |
| 占用格 | occupiedPositions，物件占据的网格点集合 |
| 容器物件 | kind: 12 区域，可嵌套子物件 |

## 二、核心功能需求

### 2.1 文件管理

#### 2.1.1 打开 / 读取关卡

**支持来源**：
- 本地文件选择（`arrowJam-main-level-{N}.json`）
- 拖拽文件至编辑器窗口
- 批量打开同一目录下的多关卡

**解析规则**：
- 必填顶层字段缺失 → 弹窗提示并阻止加载
- instanceId 冲突 → 提示并自动重分配
- 嵌套 kind:12 的 items 中子项 instanceId 同样不可重复

**展示内容**：解析成功后，在画布中央渲染棋盘与全部物件

#### 2.1.2 保存关卡

**保存方式**：
- **保存**：覆盖原文件
- **另存为**：弹出文件选择框，强制遵循 `arrowJam-main-level-{N}.json` 命名规范
- **导出**：导出到自定义路径（用于备份或分享）

**保存前校验**：见 §2.5 数据校验

**写入格式**：JSON 美化（2 空格缩进、UTF-8、字段顺序稳定）

#### 2.1.3 新建关卡

弹出新建向导：
- width（默认 20，最大 255）、height（默认 32，最大 255）
- name（可空）、durationInSec（默认 150）
- difficulty（1=Normal / 2=Hard / 3=Superhuman）
- levelKind（可选，主线/普通）

创建后自动分配 instanceId（建议从 1 起递增）

---

### 2.2 关卡基础参数编辑

提供"关卡信息"属性面板，可编辑以下字段：

| 字段 | 类型 | 约束 | UI 控件 |
|------|------|------|---------|
| width | int | 255≥width≥20 | 数字输入框 |
| height | int | 255≥height≥20 | 数字输入框 |
| name | string | 可空 | 单行文本 |
| durationInSec | int | ≥1 | 数字输入框（秒） |
| difficulty | enum | 1/2/3 | 下拉选择 |
| levelKind | int | 可选 | 下拉选择 |

修改 width/height 时，弹出确认对话框："调整棋盘尺寸可能裁切/留白现有物件，是否继续？"

---

### 2.3 物件编辑

#### 2.3.1 通用编辑能力

- **新增物件**：从左侧工具栏选择 kind → 在画布上点击/拖拽放置
- **选中物件**：单击高亮，右侧属性面板显示字段
- **移动物件**：拖拽整体平移（占用格坐标同步更新）
- **删除物件**：Delete 键或右键菜单
- **复制/粘贴**：Ctrl+C / Ctrl+V
- **instanceId**：自动分配，UI 上隐藏但可在高级视图中查看

#### 2.3.2 按类型编辑细节

##### ▶ Kind 1：折线箭

**绘制方式**：点击拖动形成折线，末格为头部

**可编辑字段**：
- direction（1=下 / 2=上 / 3=右 / 4=左）— 头部指向
- colorId（3=红 / 4=紫 / 6=绿 / 7=蓝）
- layer（默认 2）

**约束**：
- 折线不可自交
- 末格必须与 direction 步进向量一致

##### ▶ Kind 3：管道

**绘制方式**：点击拖动生成折线/蛇身

**可编辑字段**：
- health（血量）
- passes（出入口配置）：每端 {position, directions[]}
- healthViewPathIndex（UI 锚点索引）

**约束**：
- passes 必须在 occupiedPositions 内
- directions 必须是允许的反射向量（如 [1,0]、[0,-1] 等）

##### ▶ Kind 4：反射角块

**绘制方式**：单格放置

**可编辑字段**：
- direction1（允许穿出方向之一）
- direction2（允许穿出方向之二）

**约束**：
- direction1 与 direction2 必须互相垂直（90°折射）
- 不能指向角块"后方"（即不能配置为让箭反射回原路）

##### ▶ Kind 6：幕布

**绘制方式**：拖拽框选矩形区域

**可编辑字段**：
- health（血量）
- order（消除/激活顺序）
- layer（固定为 8，不可改）

**约束**：
- occupiedPositions 必须是连续的矩形
- 不同幕布 order 唯一性建议，幕布消除需要按照 order 的顺序
- 每消除一个 kind:11 绑定的箭，order 值最小的幕布血量-1，该幕布消除后，钥匙箭消除的计数目标更换下一个幕布

##### ▶ Kind 8：捆绑箭

**绘制方式**：先选 Kind 1 箭 → "捆绑"命令 → 框选附加段

- layer：固定为 3

##### ▶ Kind 11：钥匙箭

**绘制方式**：单格放置

**绑定规则**：和格子位置上的 kind:1 箭进行绑定

- layer：固定为 3

##### ▶ Kind 12：区域容器

**绘制方式**：拖拽框选矩形

**子项编辑**：双击进入子区域，递归编辑 items[]

**子项支持类型**：kind 1、4、8（坐标使用全局棋盘坐标）

- layer：固定为 1

---

### 2.4 可视化画布

#### 2.4.1 渲染规则

**坐标系**：x 向右、y 向下，原点在左上角

**层级显示（从底到顶）**：
- layer 1: kind 12 区域背景
- layer 2: kind 1 箭、kind 3 管道、kind 4 角块
- layer 3: kind 8 捆绑、kind 11 钥匙
- layer 8: kind 6 幕布

**辅助功能**：
- 网格线、坐标标尺
- 缩放（鼠标滚轮，10%~800%）
- 平移（按住空格 + 拖拽）
- 占用格高亮（hover 时显示 [x, y] 坐标）

#### 2.4.2 视觉配色

| 状态 | 视觉表现 |
|------|----------|
| colorId 3 / 4 / 6 / 7 | 红色 / 紫色 / 绿色 / 蓝色 填充 |
| 选中态 | 黄色描边 |
| 非法态 | 红色闪烁 |
| Hover 占用格 | 高亮 + 浮动 tooltip 显示 [x, y] |

---

### 2.5 数据校验

保存前必须通过以下校验，否则禁用保存按钮并列出问题清单：

| 校验项 | 规则 | 错误等级 |
|--------|------|----------|
| 顶层字段完整性 | width/height/itemModels 必须存在 | 阻塞 |
| instanceId 唯一性 | 同关内（含嵌套）不重复 | 阻塞 |
| 坐标范围 | 所有 occupiedPositions 在 [0, width) × [0, height) | 阻塞 |
| 折线连续性 | kind 1/3 相邻格必须首尾相接 | 阻塞 |
| 矩形完整性 | kind 6/12 的 occupiedPositions 必须为完整矩形 | 阻塞 |
| kind 12 嵌套约束 | 子项只能为 kind 1/4/8 | 阻塞 |
| passes 配置 | kind 3 的 passes 必须在 occupiedPositions 内 | 阻塞 |
| 角度约束 | kind 4 的 direction1 与 direction2 垂直 | 警告 |
| 反射约束 | kind 4 配置不能指向角块后方 | 阻塞 |

---

### 2.6 辅助功能

- **关卡预览**：内置"试玩"模式，模拟箭飞出、管道消除、角块反射、幕布解锁流程

## 三、UI 界面设计

### 3.1 整体窗口布局

主窗口采用经典的「左侧工具栏 + 中央画布 + 右侧属性面板 + 顶部菜单」四区结构，支持窗口缩放、最小/最大化，多任务时可同时打开多个关卡文件。

```
┌─────────────────────────────────────────────┐
│  菜单栏 / 工具栏                              │
├──────────┬──────────────────────┬───────────┤
│          │                      │           │
│  物件    │    画布主区域         │  属性面板  │
│  工具栏  │  (棋盘网格+物件渲染)  │           │
│          │                      │           │
├──────────┴──────────────────────┴───────────┤
│  状态栏（坐标、缩放比例、提示信息）            │
└─────────────────────────────────────────────┘
```

### 3.2 菜单栏与工具栏

| 区域 | UI 元素 | 对应功能 |
|------|---------|----------|
| 菜单栏 - 文件 | 新建 / 打开 / 保存 / 另存为 / 导出 / 退出 | §2.1 文件管理 |
| 菜单栏 - 编辑 | 撤销 / 重做 / 复制 / 粘贴 / 删除 | §2.3.1 通用编辑 |
| 菜单栏 - 视图 | 缩放 / 重置视图 / 网格显示 | §2.4 可视化 |
| 菜单栏 - 工具 | 试玩预览模式 | §2.6 辅助功能 |
| 菜单栏 - 帮助 | 类型说明 / 快捷键 | §1.3 术语 |
| 快捷工具栏 | 常用操作图标按钮 | 提升高频操作效率 |

### 3.3 左侧物件工具栏

用于新增物件的入口，按 kind 分类展示，每个图标 hover 时显示名称和简要说明：

- Kind 1：折线箭
- Kind 3：管道
- Kind 4：反射角块
- Kind 6：幕布（矩形工具）
- Kind 8：捆绑箭（依赖已选中的 Kind 1）
- Kind 11：钥匙箭
- Kind 12：区域容器（支持双击进入子层编辑）

### 3.4 中央画布主区域（核心可视化区）

#### 3.4.1 棋盘渲染

- **网格线**：浅灰细线，10% 缩放以下自动隐藏
- **坐标标尺**：顶部显示 x（列号）、左侧显示 y（行号）
- **层级渲染（从底到顶）**：
  - layer 1 → Kind 12 区域背景
  - layer 2 → Kind 1 箭 / Kind 3 管道 / Kind 4 角块
  - layer 3 → Kind 8 捆绑 / Kind 11 钥匙
  - layer 8 → Kind 6 幕布

#### 3.4.2 颜色与状态

| 状态 | 视觉表现 |
|------|----------|
| colorId 3 / 4 / 6 / 7 | 红色 / 紫色 / 绿色 / 蓝色 填充 |
| 选中态 | 黄色描边 |
| 非法态 | 红色闪烁 |
| Hover 占用格 | 高亮 + 浮动 tooltip 显示 [x, y] |

#### 3.4.3 视图控制

- **缩放**：鼠标滚轮，范围 10% ~ 800%
- **平移**：按住空格 + 鼠标拖拽
- **重置视图**：菜单 / 快捷键回到 100% 居中

### 3.5 右侧属性面板

根据当前选中物件动态切换显示内容，无选中时显示「关卡信息」面板。

#### 3.5.1 关卡信息面板（无选中物件时显示）

| 字段 | UI 控件 |
|------|---------|
| width | 数字输入框（20~255） |
| height | 数字输入框（20~255） |
| name | 单行文本框 |
| durationInSec | 数字输入框（≥1） |
| difficulty | 下拉选择（Normal / Hard / Superhuman） |
| levelKind | 下拉选择（主线 / 普通） |

修改 width / height 时弹出确认对话框：「调整棋盘尺寸可能裁切/留白现有物件，是否继续？」

#### 3.5.2 物件属性面板（按 kind 分组）

| Kind | 关键字段 | 控件形式 |
|------|----------|----------|
| 1 折线箭 | direction、colorId、layer | 下拉 + 颜色选择器 |
| 3 管道 | health、passes（出入口）、healthViewPathIndex | 数值 + 端点编辑器 |
| 4 角块 | direction1、direction2 | 方向选择器（自动校验垂直） |
| 6 幕布 | health、order | 数值输入（order 唯一性提示） |
| 8 捆绑 | （继承 Kind 1 属性 + 附加段编辑） | 折线段编辑器 |
| 11 钥匙 | 绑定规则 | 显示绑定 Kind 1 所处的任意一个 [x，y] 坐标 |
| 12 区域 | items[] | 树形列表 + 双击进入子层 |

#### 3.5.3 高级视图

默认隐藏 instanceId，在「高级视图」中以只读方式列出，方便排查冲突。

### 3.6 对话框与弹窗

| 触发条件 | 弹窗内容 | 错误等级 |
|----------|----------|----------|
| 打开文件 | 必填字段缺失提示、instanceId 冲突自动重分配说明 | 阻塞 |
| 修改 width/height | 裁切/留白确认 | 警告 |
| 保存关卡 | 数据校验问题清单（按 §2.5 表格逐项列出） | 阻塞 / 警告 |
| 反射角块配置 | direction1 与 direction2 不垂直 | 警告 |
| 反射角块配置 | 方向指向"后方" | 阻塞 |
| 另存为 | 文件名强制遵循 `arrowJam-main-level-{N}.json` 规范 | 强制 |

### 3.7 状态栏

- **左**：当前光标所在格坐标 [x, y]
- **中**：缩放百分比、当前选中物件信息
- **右**：保存状态（已保存 / 未保存 / 校验未通过）、提示信息

### 3.8 辅助功能 UI

- **试玩预览模式**：进入后工具栏禁用编辑能力，改为播放控件（开始 / 暂停 / 步进 / 重置），用于模拟箭飞行、管道消除、角块反射、幕布解锁流程
- **拖拽支持**：文件拖拽到窗口空白处触发「打开」流程
- **批量打开**：支持一次选择多个 `arrowJam-main-level-{N}.json`，通过标签页切换

### 3.9 快捷键建议

| 快捷键 | 功能 |
|--------|------|
| Delete | 删除选中物件 |
| Ctrl + C / V | 复制 / 粘贴 |
| Ctrl + S | 保存 |
| Ctrl + Shift + S | 另存为 |
| Space + 拖拽 | 平移画布 |
| 滚轮 | 缩放画布 |
| Esc | 退出试玩预览 / 取消当前绘制 |
