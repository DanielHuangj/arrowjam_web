# Arrow Jam 新增规则内容

## 名词解释

**覆盖状态**：当箭头是处于未开启的子区域、幕布下，或者冰冻状态中，即属于覆盖状态。

---

## 新增类型

### 一、kind2 翻转箭 (Flip Arrow)

每当消除 kind1 或 kind2 物件时，改变一次棋盘内剩余 kind2 翻转箭的方向。多个 kind1 或 kind2 同时消除时，视为一次，如：消除一组捆绑箭或使用同时消除多个箭头道具时。

翻转箭只有处于**非覆盖状态**时，才能激活翻转特性。

**翻转的动效**：翻转箭的箭头先进行翻转，然后沿着箭身移动，到达箭身末端，即完成翻转。

#### 参数作用定义

| 参数 | 说明 |
|------|------|
| direction1 | 默认指向、配置中的最后一格作为翻转前的头部 |
| direction2 | 翻转指向、配置中的第一格作为翻转后的头部 |
| layer | 和 kind1 参数一致 |
| colorId | 和 kind1 参数一致 |
| occupiedPositions | 和 kind1 参数一致 |

**校验规则**：头尾朝向均不能被自身包含的棋盘坐标阻挡。

可加入至 kind12 区域容器中

---

### 二、kind5 定时炸弹 (Timed Bomb)

1. 定时炸弹绑定在已有的 kind1 或 kind2 的物件坐标上
2. 玩家需要在倒计时结束前将绑有定时炸弹的 kind1 或 kind2 物件消除
3. 超时则炸弹爆炸导致本局游戏失败
4. 在覆盖状态下的定时炸弹，只有覆盖状态被解除，才会激活，开始倒计时
5. 炸弹显示效果：初始时是一个带有倒计时钟的，爆炸是一个大的烟尘效果

#### 参数作用定义

| 参数 | 说明 |
|------|------|
| occupiedPositions | 定时炸弹绑定的 kind1 棋盘坐标 |
| time | 炸弹爆炸倒计时，激活状态下倒计时启动 |
| layer | 固定为 3，和 kind8、kind11 相同 |

可加入至 kind12 区域容器中

---

### 三、kind7 移动墙 (Moving Wall)

1. 每消除一个 kind1 或 kind2 物件时，kind7 物件按照配置路径移动
2. kind7 物件在 kind1、kind2 物件的朝向前方时，会阻挡 kind1、2 物件的消除
3. 根据配置的坐标格组成路径进行移动
4. 移动路径执行方式分为**往复**或**循环**两种

#### 移动方式说明

- **往复循环**：到达配置的最后一格时按照配置路径反向向第一格移动，并反复这个过程
- **环绕循环**：移动路径的头尾是虚拟连接在一起的，当移动墙到达配置的最后一格时，会穿越回第一格继续沿路径移动，并反复这个过程

#### 参数作用定义

| 参数 | 说明 |
|------|------|
| occupiedPositions | kind7 物件的初始坐标及占用格子数 |
| layer | 层级和 kind1 类型一致 |
| movingPath | kind7 物件移动时必须遵循的单元格坐标 |
| movingDistance | kind7 物件每次移动的单元格数 |
| movingType | 移动路径执行方式：1、往复循环；2、环绕循环 |

---

### 四、kind13 冻结箭 (Frozen Arrow)

1. 冻结区域与整个 kind1 或 kind2 进行绑定
2. 消除相邻格上的箭头会让冻结区域的 health 减 1，当 health 归 0 即解除冻结状态
3. 冻结区域和绑定的 kind1、kind2 占用相同格数
4. 当多个冻结区域有公共的非冻结箭头区域，当公共箭头消除时，相邻的多个冻结区域的 health 都要减 1
5. 冰冻显示用冷蓝色的不规则晶状表示

#### 参数作用定义

| 参数 | 说明 |
|------|------|
| health | 血量，需要消除的临近箭头数量 |
| layer | 固定为 8，不可改 |
| occupiedPositions | 冻结区域占用的格子坐标数组 |

可加入至 kind12 区域容器中
