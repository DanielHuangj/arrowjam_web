# **Arrow 玩法规则详解**

# **一、游戏目标**

   在倒计时结束前，将棋盘上所有带箭头的线条全部发射出去（后续简称箭头），清空棋盘。
   一个箭头由1-N个连续单元格组成，线条走向可以为折线。

# **二、基本操作**

   "点击"一个箭头 → 该箭头沿其指向方向飞出
	箭头只能在其"指向方向上路径畅通"时才能被点击发射
	"路径畅通" = 从箭头位置到棋盘边缘之间，没有任何其他箭头阻挡

# **三、箭头的朝向**

每个箭头固定指向四个基本方向之一:
   ↑ 上
   ↓ 下
   ← 左
   → 右
箭头只能沿自己指向的方向直线飞行，不能斜向移动。

# **四、路径判定规则**

## 畅通条件

- 从箭头所在位置出发，沿其指向方向逐格检查:
- 如果该方向上"紧邻的格子为空"（或已无箭头），则可以发射
- 如果该方向上"有其他箭头挡在前面"，则该箭头当前不可发射（被"jam"住了）

## 阻塞与解锁

- 被阻挡的箭头需要等待"前方的箭头先被发射"，路径才会打开
- 这就是"Jam"的含义 —— 箭头互相卡住，需要找到正确的发射顺序来逐一解锁

# **五、障碍机制详解**

1. 联动箭头 (Linked Arrows)
  两个或多个箭头被"连接"在一起（视觉上有线/链条相连）
   当其中一个被发射时，"其他联动箭头也会跟着一起移动/发射"
   联动箭头的方向可能不同，因此一次操作可能同时清空多条路径，也可能把关键路径上的箭头意外带走
   "策略要点": 需要预判联动效果，避免破坏后续需要的发射顺序
2. 转向箭头 (Corner Arrows)
  这类箭头在飞行过程中会"改变方向"（如先向上飞，碰到转角后变为向右）
   棋盘上存在转角标记点，箭头经过时自动转向
   发射前需要预判"转向后的最终路径"是否畅通
   "策略要点": 转向后的路径也可能被其他箭头阻挡，需要综合判断
3. 管道系统 (Pipes)
  棋盘上存在管道入口和出口
   箭头飞入管道入口后，会从"对应的管道出口"飞出
   管道可以跨越棋盘上的障碍，实现"传送"效果
   管道两侧在棋盘上以障碍的方式阻挡两侧箭头消除
   通过管道飞出指定数量的箭头后，管道消失，解除对管道两侧箭头的阻挡
   "策略要点": 管道出口方向可能指向被阻挡的区域，需要确保出口路径也畅通
4. 帷幕 (Curtain)
  棋盘上某些区域被帷幕遮挡，需要指定数量的锁定箭头解除帷幕
   帷幕解除后展现帷幕下被遮挡的箭头
   帷幕在未解除时会以障碍的方式阻挡周围的箭头消除
5. 钥匙箭 (Key Arrows)
  部分箭头会绑定钥匙，通过消除钥匙箭收集点数解锁帷幕。
   需要先找到并发射特定的"钥匙箭头"
   或者需要先消除钥匙箭头周围的所有阻挡，使其自动解锁
   "策略要点": 要是箭头往往是关键路径上的节点，需要优先规划解锁顺序
6. 多层区域 (Stacked Zone)
  某些位置可能有"多层区域"
   必须先发射区域范围最上层的箭头，才能看到/操作下层的箭头
   下层箭头的方向可能与上层完全不同

# **六、胜负条件**

## 胜利条件

- 在倒计时归零前，将棋盘上"所有箭头全部发射出去"

## 失败条件

- "倒计时归零"但棋盘上仍有箭头未清除
- （部分版本）步数用尽 —— 但 Arrow Jam 主打时间限制而非步数限制

## 评价机制

- 通关后根据"剩余时间"和"操作失误次数"给出评价
- 评价等级: excellent → well done → amazing → magnificent → superb → terrific

# **七、关卡设计逻辑**

难度递进维度

1. "箭头数量": 从少量箭头逐步增加到密集棋盘
2. "障碍类型叠加": 先引入单一机制，后期多种机制混合
3. "路径复杂度": 从直线畅通路径到需要多次解锁的深层嵌套
4. "时间压力": 后期关卡时间更紧，容错更低
5. "棋盘规模": 部分关卡超过1屏，需要滚动/拉伸查看全貌

典型关卡结构

1. "外层箭头": 位于棋盘边缘，路径畅通，可直接发射 —— 用于热身和建立节奏
2. "中间层箭头": 被外层箭头部分阻挡，需要先清除外层才能解锁
3. "核心箭头": 位于棋盘中心，被多层包围，需要精确的发射顺序
4. "特殊机制箭头": 联动/转向/管道/锁定箭头散布在各层，增加变数
