# Arrow Jam 新版本规则初稿（爽快版）

核心玩法大的改动，以下分几个方面说明：

---

## 一、物件自动生成

增加一个核心机制，当箭头被消除后，空闲出来的棋盘空格，会自动生成新的物件，包括箭头、机制物件、增益道具。

### 生成规则

#### 1. 填充比例
根据关卡设定难度，每次空格被填充的比例不一样：
- **Normal**: 70-80%
- **Hard**: 80-90%
- **SuperHard**: 90-100%

范围内随机。

#### 2. 可生成物件配置
关卡可以生成的物件，由关卡文件进行配置，只有配置的物件才会在本关生成。并且可以配置不同物件生成的概率。

**特别说明**：
- 箭头除了区分kind1和kind2，还可以设置颜色，也就是设定不同颜色的箭头的出现概率
- 其中一种颜色叫**通用色**，这个颜色是指生成时会在所有游戏箭头可用颜色中，随机抽取颜色来生成箭头

#### 3. 箭头生成规则
- 生成物件是箭头时，生成的箭头占格数为**2-6之间随机**
- 格子必须连续
- 箭头方向和最后一段箭身方向一致
- 如果是其他物件，必须有足够放置的空格才能生成

#### 4. 机制物件生成
目前支持生成的机制物件，**只有反射角**，生成反射角的时候，反射角的反射面随机生成。

#### 5. 生成周期
关卡可以配置一个**生成周期**，单位为秒。
- 开始后，会启动一个倒计时
- 按照关卡配置的生成周期时间进行倒计时
- 倒数完就启动一次物件的自动生成
- 然后重新开始倒计时
**注意：如果棋盘上所有的箭头都被消除完了，这个时候，会马上启动自动生成，并且刷新倒计时**。

#### 6. 动态概率调整
在生成周期的倒计时时间内，记录这段时间消除的箭头所占的格子总数，这个数量会影响生成物件的生成概率。
注意当本次（不是本关）自动生成的物件已经出现了一次增益道具，则本次自动生成的后面轮次的概率都将恢复到原配置。即动态概率调整的影响只持续到生成了增益道具为止。
这个概率和关卡关联，每个关卡都可以独立设置。

**具体规则**：

| 消除格子数 | 增益道具概率     | 箭头概率      | 机制物件概率    |
| ----- | ---------- | --------- | --------- |
| 0-30  | 原配置        | 原配置       | 原配置       |
| 30-60 | +10%（多个均分） | -5%（多种均分） | -5%（多个均分） |
| >60   | +20%       | -10%      | -10%      |

**特殊情况处理**：
- 如果箭头或者机制物品配置概率不足扣减时，则减到0
- 剩余的由另外一个补足
- 如果合起来的概率不足扣减时，则都减为0，而增益道具生成概率为100%

#### 7. 生成逻辑
进行物件生成时：
1. 先根据概率抽取一个要生成的物件
2. 如果物件是非箭头，则根据物件确认其需要的格子数
3. 如果有足够的连续的空闲格子，即可生成
4. 如果空间不足，则跳过，进行下一次的概率抽取
5. 如果抽取到的是箭头：
   - 剩余的连续格子≥6：在2-6之间随机生成一个箭头
   - 剩余的连续格子<6：按照剩余的连续格子数生成（必须>1）
6. 箭头的方向随机，但是箭头方向要和箭身方向趋势一致

**单次生成的结束判断**：
1. 已经没有空闲格子了
2. 剩余总格子数不足5个，并且连续3次生成判断，都无法生成新的物件
3. 剩余的所有格子都是单格的，并且连续3次生成判断，都无法生成新的物件
4. 生成次数超过了200次（防卡死）

#### 8. 生成表现
- 在生成的过程是没有效果的
- 当生成完了所有的物件后，所有物件会在其所在位置，以**从透明到完全显现**的方式出现在位置上
- 生成的过程会**暂停棋盘的点击响应**，即在生成的过程无法进行箭头的点击消除

## 二、增益道具

增加多个增益道具，增益道具可以配置在关卡中，也可以通过自动生成出现在关卡中。

不同的增益道具有不同的使用方式或者是触发方式。当增益道具被使用或者是触发，则会产生各种特殊的效果，效果因不同道具各异。目前只设定了几种增益道具，后续会逐步增加。

### 1. 区域炸弹

**外观**：红色的捆绑式炸弹样式，带引信不带定时器的。占一格。

**触发方式**：手动触发（点击触发）+ 箭头穿越触发（箭头不需要能被消除）+ 连续触发

**效果**：
- 产生爆炸效果
- 把以自身为中点的，一个N×N区域内的箭头格子摧毁（即该格子上的箭头部分会消失）
- 如果箭头所占格子并非都在爆炸区域内，导致箭头被分割为1个或者多个部分，则按照"箭头分割处理规则"处理

**类型**：
- **小炸弹**：影响区域3×3
- **大炸弹**：影响区域5×5

**限制**：该道具不影响箭头外的机制物品。

### 2. 十字炸弹

**外观**：绿色的菠萝手榴弹样式。占一格。

**触发方式**：手动触发（点击触发）+ 箭头穿越触发（箭头不需要能被消除）+ 连续触发

**效果**：
- 产生连环爆炸效果
- 以自己为中心，按照十字的路径，同时向四个方向往外延伸
- 逐格产生爆炸，直到设定的爆炸长度
- 十字炸弹所影响的格子上的箭头都会被摧毁
- 如果导致箭头被分割，则按照"箭头分割处理规则"处理

**类型**：
- **小十字炸弹**：5×5的十字，宽度1格
- **大十字炸弹**：10×10的十字，宽度1格

**限制**：该道具不影响箭头外的机制物品。

### 3. 燃烧弹

**外观**：浅绿色燃烧瓶样式。占一格。

**触发方式**：手动触发（点击触发）+ 箭头穿越触发（箭头不需要能被消除）+ 连续触发

**效果**：
- 产生爆炸效果
- 把以自身为中点的，一个3×3区域内的箭头引燃
- 燃烧的箭头会逐格的引燃这个箭头不在爆炸区域内的其他箭头格子
- 直到整个箭头的所有格子被引燃，最后消失

**限制**：该道具不影响箭头外的机制物品。

### 4. 定向气球

**外观**：白色气球形态。占一格。

**触发方式**：**不是点击触发**，而是需要用箭头进行撞击触发，箭头进行撞击不需要箭头能被消除，只要能触碰到定向气球即可。还可以被炸弹（区域炸弹、十字炸弹、燃烧弹）引爆，引爆时会自动取棋盘上数量最多的箭头的颜色，然后完成和箭头撞击后一样的逻辑。

**效果**：
- 定向气球被撞击后，首先会根据撞击它的箭头的颜色，变换为这种颜色的气球
- 然后会产生一个膨胀破裂的效果，就类似被吹爆的过程
- 同时，棋盘上**所有同样颜色的箭头**都会产生一个膨胀破裂的效果，并最终消失

**限制**：该道具不影响箭头外的机制物品。

### 5. 黑洞

**外观**：中心是一个黑色圆形，外围有一小圈白边，白边外有螺旋向外发散状的半透明白带。

**触发方式**：**非触发装置**，点击无效。

**效果**：
- 黑洞是一个箭头的消亡点
- 黑洞只存活10秒，从它生成开始算，10秒后，这个黑洞就会消失，消失的时候会表现一个内收的效果。
- 箭头通过黑洞时，会被吞噬，最终消失
- 通过黑洞消除的箭头和点击消除的箭头产生的效果一致，会被计算消除条目数和格子数等
- 每次箭头通过黑洞被吞噬的时候，黑洞会产生一个旋转的效果

### 6. 翻转按钮

**外观**：白色黑边圆盘上有两个箭头，上下并排，方向指向相反。

**触发方式**：手动触发（点击触发）+ 箭头穿越触发（箭头不需要能被消除）。

**效果**：
- 当翻转按钮被触发后，随机选取棋盘上50%的箭头产生头尾翻转，即被选中的箭头执行一次翻转箭翻转规则。

### 7. 糖果机

**外观**：一个扭蛋糖果机的样子，上部是大玻璃罩，下部是一个扭蛋按钮，大玻璃罩里面是五彩的圆形糖果。

**触发方式**：手动触发（点击触发）+ 箭头穿越触发（箭头不需要能被消除）+ 连续触发

**效果**：
- 触发后，先从棋盘上随机选取8个箭头，并在8个箭头上随机取一个格子
- 然后会糖果机会往这个格子发射一个彩色（颜色随机）的圆形糖果
- 糖果飞到这个格子后就会消失，飞行过程中带一点点拖尾
- 同时这个格子所属的箭头开始产生一个膨胀破裂的效果，并最终消失（效果参考定向气球引起的箭头碰撞特效）

### 8. 连续触发规则

部分增益道具会相互触发，产生连爆的效果。目前会连续触发的增益道具包括：区域炸弹、十字炸弹、燃烧弹。

连续触发具体规则是：当一个在连续触发规则内的增益道具被触发了，在它影响的区域内，如果有其他的在连续触发规则内的增益道具，那这些道具都会被触发，并延迟0.5后，开始被触发的效果。这个触发是连续性的，如果被其他道具触发的道具范围内又有其他的连续触发道具，则会继续被触发。

### 9. 自动刷新规则

当棋盘上所有的箭头都被阻挡，无法消除，并且所有的可触发增益道具都没法被触发，那棋盘上的箭头将会被自动刷新。自动刷新的效果是：随机选取棋盘上的一半箭头，执行一次翻转箭翻转规则。

**注意：增益道具无法被触发的意思是，无论那种道具支持的触发模式，都不能触发这个道具的效果。比如定向气球，如果没有任何的箭头能撞击它，并且它周边也没有可以引爆它的其他增益道具，则这个定向气球就是无法被触发的。**

### 10. 箭头分割处理规则

在很多增益道具使用后，都可能导致原先一体的箭头被分割为1个或者多个部分，这里需要一个统一的处理规则：

| 剩余情况 | 处理方式 |
|---------|---------|
| 只剩1个格子 | 播放湮灭效果后消失 |
| 剩余≥2格，且箭头格还存在 | 处理尾部，变成标准的箭头尾部（标准箭头尾部是箭头只画半格的） |
| 剩余≥2格，且不带箭头格 | 在原来最靠近箭头的格子上，按照原来的延伸方向，生成一个新的箭头 |

### 11. 连消（Combo）规则

连消可由关卡配置开关控制（字段 `comboEnabled`，缺省为开启）。关闭后本关不累计连消、不显示 Combo UI、不因连消推迟刷盘，也不发放连消奖励增益。

连消表示在设定时间内连续完成消除。初始 **combo 时间 = 2 秒**；每次成功连消后，下一轮 combo 时间减为上一次的 **95%**（缩短 5%）。

**记入连消**：箭头成功出界消除，或被黑洞 / 黑洞区域吞噬。

**连消中断**：
- combo 倒计时结束仍无完成一次消除；
- 点击箭头但被阻挡；
- 使用或触发除黑洞以外的其他增益道具。

**与自动生成**：连消期间生成倒计时**照常倒数**；归 0 后若仍在连消中则不刷盘，倒计时保持为 0。连消结束后若倒计时已为 0，则立即刷盘并重置生成倒计时。每达到 **10 / 20 / …** 次连消，从本关 `spawnPool` 中的增益道具条目均分抽取一个，投放到随机空格（无增益配置则不生成）。

**表现**：棋盘上方中央显示橘黄像素风 `COMBO x N` 与橘黄进度条；每次连消有放大缩小脉冲（间隔越短脉冲越快）；满 10 整数次时道具从字样处飞入落点并逐渐放大。

## 三、棋盘优化

### 1. 异形棋盘

棋盘一般是正方形的，正方形内的所有格子都是有效格子，都能放置各种物件，也能生成物件。但是为了关卡的趣味性，还需要增加异形的棋盘。

异形棋盘即不规则的棋盘，只有设定的有效格子才能放置物件和生成物件，其他的格子和背景同色，并且也不显示中心的圆点。

异形棋盘的编辑支持手动选择有效格子，也支持导入图片，根据图片的像素规则，自动设定有效格子，方便策划生成复杂度较高的异形棋盘。详细需求见文档的编辑器部分。

需要优化关卡存储，非异形棋盘，表示整个棋盘的格子都是有效的，不需要再记录有效格子坐标。另外即便是异形棋盘，其有效格子也是连片的，所以多利用连续格子的特点来设计存储方式，尽量减少关卡文件的大小。所以关卡信息中要能区分异形棋盘还是正常棋盘。

### 2. 黑洞区域

目前的核心玩法有个问题，就是箭头的出口只有外围4个方向，异形棋盘能一定程度上让出口产生一定变化，但是4个方向还是不变的。为了让玩法的趣味性增加，需要在棋盘上可以设定一个或者多个的黑洞区域。注意黑洞区域无论是正常棋盘还是异形棋盘都是可以使用的。

黑洞区域是有多个连续相邻的格子组成，这个区域是能进行箭头消除的，也就是箭头飞入该区域即算是完成消除，规则和增益道具黑洞一致。黑洞区域中的格子是不会生成物件的。

这个区域的编辑支持手动选择格子，也支持图片中根据像素生成。详细需求见文档的编辑器部分。

表现方面，黑洞区域不能放置物件，格子不显示中心的圆点，黑洞区域的格子背景不是白色，而是模拟星空的景色，由多个颜色的彩色烟尘，不断变换，来做表现。


## 四、结算规则

### 1. 关卡目标

关卡的通过判断**不再是清空棋盘上所有箭头**，而是在规定时间内达成被关卡所设定的目标。

**目前设定的关卡目标主要有2种**：

1. **消除指定数量的箭头**
   - 通过道具消除的箭头，如果箭头产生了分割，则分割出来的箭头算是新的箭头
   - 而被消除的部分整体算1个消除

2. **消除指定颜色的指定数量箭头**
   - 可以是多种颜色箭头的复合目标
   - 通过道具消除而产生分割的箭头，规则如前所述

### 2. 胜利结算与通关庆祝

达成关卡设定目标则算胜利。爽快版在弹出结算窗之前，先播放庆祝流程：

1. **能量球（进行中）**：棋盘右侧显示透明能量球；若关卡配置了「消除箭数」（`clearArrowCount`），则按该目标进度以紫色药水填充，每次消除有水波动效；填满对应该目标数量。无此目标时不显示能量球。
2. **Bingo**：目标全部达成后，中央弹出 `Bingo` 字样（小→大→呼吸收缩→消失）。
3. **飞出道具**：Bingo 结束后，从能量球（或右侧锚点）向空闲格飞入最多 **10** 个道具（空格不足则填满即止）；种类在区域炸弹 / 十字炸弹 / 糖果机中随机。
4. **自动触发**：道具落地后按投放顺序每隔 **0.2 秒** 自动触发；随后将棋盘上剩余可主动触发的增益（不含气球、黑洞）同样逐一触发，直到没有剩余。
5. **撒花**：全部相关效果结束后，棋盘范围撒花约 **1 秒**，再弹出结算窗口。

### 3. 失败结算

在关卡时间完结前没有达成关卡目标，则算失败。

## 五、编辑器

根据新的核心机制修改，编辑器要同步进行修改，包括以下部分：

### 1. 关卡的基础配置

要增加基础配置的信息，包括：
- 生成周期
- 生成物品添加
- 生成物品的配置

**操作上**：
- 在关卡信息配置界面，可以通过下拉菜单选择生成物品添加
- 可生成物品包括：所有的箭头、部分机制物品（目前只支持反射角）和增益道具
- 所有生成物品都要设置生成概率，并且保证总概率为100%
- 添加的生成物品为箭头的时候，还需要设置其颜色
- 不同颜色的箭头可以视为不同物件，但不允许配置两个同类型并且颜色也一样的箭头

### 2. 关卡道具编辑

把增益道具加入到关卡编辑物件工具箱，可以在编辑关卡的时候，加入这些道具。

**需要添加时**：
- 在工具箱选择要添加的道具
- 再点击棋盘放置即可

### 3. 特殊区域编辑

特殊区域包括了异形棋盘和黑洞区域。

异形棋盘和黑洞区域就是一堆连续的相邻的格子，需要支持在棋盘上编辑区域格子。

首先，在关卡编辑界面的棋盘右侧增加三个按钮，一是异形棋盘编辑，二是黑洞区域编辑，三是导入背景图。

点击异形棋盘编辑进入异形棋盘的编辑状态，这个时候可以在棋盘上单选格子，也可以拖动选择连续的多个格子，被选中的格子会变成绿色底。如果格子已经被选中，变成绿色后，再次点击则会取消选中，格子变回原状态。完成棋盘有效格子（所有绿色格子）的选择后，点击编辑完成，则会保存这些有效格子，并且棋盘上的无效格子都会被置灰，后续不能在无效格子上放置物件。

点击黑洞区域编辑进入黑洞区域编辑状态，这个时候可以在棋盘上单选格子，也可以拖动选择连续的多个格子，被选中的格子会变成白色底，注意这里选择的格子必须是有效格子。如果格子已经被选中，变成白色后，再次点击则会取消选中，格子变回原状态。完成黑洞区域格子（所有白色格子）的选择后，点击编辑完成，则会保存黑洞区域的信息，并且黑洞区域的格子持续显示白色，这个白色区域不能再被放置其他的物件。

点击导入背景图，会弹出文件选择窗，在本地文件中选择一张图片，图片支持jpg和png，大小尽量不要超过2M。选择完成并确认后，这张图片将作为关卡编辑器棋盘的背景图，这个图是置于棋盘下方的，棋盘的格子线和行列编号都不会被遮挡，为了能更清晰，在导入了背景图后，格子线和行列编号都做一点加粗的显示。导入了背景图后，原来的导入按钮会变成“删除背景图”的按钮，点击会把背景图删掉。注意，背景图只是辅助区域编辑，不会出现在游戏和试玩中。

## 六、核心变化总结

### 与原版本的主要区别

| 方面 | 原版本 | 新版本（爽快版） |
|------|--------|-----------------|
| **核心循环** | 消除箭头→路径解锁→连锁消除 | 消除箭头→自动生成新物件→持续消除 |
| **关卡目标** | 清空棋盘所有箭头 | 在规定时间内达成指定目标 |
| **道具系统** | 无 | 增加多种增益道具 |
| **棋盘状态** | 静态（只减不增） | 动态（持续生成新物件） |
| **策略维度** | 发射顺序规划 | 发射顺序+道具使用时机+目标管理 |

### 新增的核心体验

1. **持续爽感**：消除后不断有新物件生成，保持消除的连续性
2. **道具策略**：增益道具的使用时机成为新的策略维度
3. **目标驱动**：从"清空棋盘"变为"达成目标"，目标感更强
4. **动态难度**：根据玩家表现动态调整生成概率，自适应难度
