# Arrow Jam 新增规则编辑器需求

## 一、新增 Kind 类型的编辑需求

根据《Arrow Jam 新增规则内容.md》文档中的 kind2（翻转箭）、kind5（定时炸弹）、kind7（移动墙）、kind13（冻结箭），需在关卡编辑器中补充以下功能：

### 1. kind2 翻转箭（Flip Arrow）

**绘制方式：**

折线箭形式，需支持方向动态切换（基于 direction1 和 direction2）。

**可编辑字段：**

- **direction1**：默认指向（配置中最后一格为头部）
- **direction2**：翻转指向（配置中第一格为头部）
- **layer**：与 kind1 一致（默认 2）
- **colorId**：同 kind1（3=红/4=紫/6=绿/7=蓝）
- **occupiedPositions**：折线占用坐标（需校验头尾朝向不被自身坐标阻挡）

### 2. kind5 定时炸弹（Timed Bomb）

**绘制方式：**

绑定在已有 kind1 或 kind2 物件坐标上（需先选中 kind1 或 kind2 箭，再通过工具栏添加，和 Kind=11 的钥匙类似）。

**可编辑字段：**

- **occupiedPositions**：绑定的 kind1 或 kind2 坐标（不可手动修改，随绑定物件移动同步更新）
- **time**：倒计时秒数（数字输入框，≥1）
- **layer**：固定为 3（与 kind8、kind11 相同）

**约束：**

一个箭只能绑定一样物件，不能同时绑钥匙、绑炸弹、设置冰冻或者是捆绑箭。

### 3. kind7 移动墙（Moving Wall）

**绘制方式：**

多格矩形区域，支持配置移动路径（拖拽定义 movingPath 坐标点）。

**可编辑字段：**

- **occupiedPositions**：初始坐标及占用格子数（矩形区域）
- **layer**：与 kind1 一致（默认 2）
- **movingPath**：移动路径坐标数组（拖拽绘制路径）
- **movingDistance**：每次移动的单元格数（数字输入框，≥1）
- **movingType**：移动方式（下拉选择：1=往复循环/2=环绕循环）

**交互逻辑：**

画布需实时模拟移动路径预览，非覆盖状态下根据 kind1/kind2 消除触发移动。

### 4. kind13 冻结箭（Frozen Arrow）

**绘制方式：**

绑定在已有 kind1 或 kind2 物件坐标上（需先选中 kind1 或 kind2 箭，再通过工具栏添加）。冻结区域与绑定的 kind1 或 kind2 占用相同格数。

**可编辑字段：**

- **occupiedPositions**：冻结区域占用的格子坐标数组（与绑定的 kind1 或 kind2 坐标一致，不可手动修改）
- **health**：血量，需要消除的临近箭头数量（数字输入框，≥1）
- **layer**：固定为 8（不可改）

**约束：**

一个箭只能绑定一样物件，不能同时绑钥匙、绑炸弹、设置冰冻或者是捆绑箭。

## 二、对原需求的修改内容

基于新增类型特性，需对原关卡编辑器需求文档进行以下调整：

### 1. 工具栏与物件类型扩展

**左侧工具栏：**

新增 4 个 kind 类型图标，分别为：kind2（翻转箭）、kind5（定时炸弹）、kind7（移动墙）、kind13（冻结箭），hover 时显示名称及规则说明（如"翻转箭：消除 kind1 时切换方向"）。

**物件绑定关系：**

原 kind8、kind11 增加 kind2 类型的绑定目标；kind5 和 kind13 可绑定 kind1 或 kind2。

**Kind 12：区域容器**

子项支持类型：原有类型 kind 1、4、8，增加 kind2、5、13 类型（坐标使用全局棋盘坐标）

### 2. 画布渲染与层级调整

**层级显示：**

- **layer 3**：原包含 kind8、kind11，新增 kind5（同层渲染）
- **layer 8**：新增 kind13（与 kind4 帷幕规则相同，同层渲染）

**视觉表现：**

- **kind13 冻结箭**：半透明蓝色覆盖层，显示剩余 health 值，标注绑定关系
- **kind7 移动墙**：高亮边框标注移动路径方向，循环/往复模式用不同颜色区分（如循环=绿色路径，往复=橙色路径）

### 3. 属性面板扩展

**新增物件属性页：**

为 kind2/5/7/13 分别添加专属属性面板，字段如下：

| kind | 字段 | 控件类型 | 约束说明 |
|------|------|----------|----------|
| kind2 | direction1/direction2 | 方向选择器（下拉） | 需校验头尾朝向不被自身坐标阻挡 |
| kind5 | time | 数字输入框（≥1） | 绑定 kind1/kind2 必须存在且非覆盖 |
| kind7 | movingPath/movingType | 路径编辑器+下拉选择 | 路径坐标需在棋盘范围内 |
| kind13 | health | 数字输入框（≥1） | 绑定 kind1/kind2 必须存在且非覆盖 |

### 4. 数据校验规则补充

在原校验项中新增以下规则：

| 校验项 | 规则 | 错误等级 |
|--------|------|----------|
| kind5 绑定有效性 | 必须绑定存在的 kind1 或 kind2 物件 | 阻塞 |
| kind7 路径完整性 | movingPath 坐标必须连续且在棋盘内 | 阻塞 |
| kind13 绑定有效性 | 必须绑定存在的 kind1 或 kind2 物件 | 阻塞 |

### 5. 辅助功能与试玩模式

**试玩模式扩展：**

按照《Arrow Jam 新增规则内容.md》文档的 kind2/5/7/13 的逻辑功能进行实现。

### 6. 术语约定补充

在原文档术语约定中新增：

| 术语 | 含义 |
|------|------|
| 翻转特性 | kind2 在非覆盖状态下，消除 kind1 时切换方向 |
| 往复循环 | kind7 到达路径终点后反向移动 |
| 环绕循环 | kind7 到达路径终点后回到起点继续移动 |
| 冻结区域解锁 | 消除指定数量临近 kind1/kind2 后解除 kind13 的冻结状态 |
