# 新增两种机制

## 新增类型

### 一、收缩障碍

**kind14：Shrink pipe**

1. 收缩障碍是绑定在管道上面的，绑定在管道的一格上，并且只在管道的一侧。
2. 收缩障碍显示上是贴邻管道侧面(无间隔)多个连续单元格，允许折线。
3. 当箭头kind1或kind2从管道一端进入并从另一端离开，障碍按照收缩格数配置向管道一侧收缩。
4. 当管道血量为零时管道和障碍消失，如果收缩障碍只剩一格，而管道血量仍有剩余，则收缩障碍不再收缩。
5. 显示：收缩障碍用两种颜色的螺旋纹，类似发廊标志灯，在和管道贴近的位置加一个卡扣的小物件，表示绑定关系。在箭头通过管道后，收缩障碍会以一个较慢的速度收缩配置好数量的单元格。

#### 参数作用定义

| 参数 | 说明 |
|------|------|
| 自身的格子路径 | 物件公共属性 |
| BindCoordinate | 绑定的管道坐标（一个格），用于标识绑定了哪个管道，以及绘制收缩障碍的起点，从第一个非管道格子开始绘制。 |
| Shorten | 箭头穿过管道时，障碍每次缩短的单元格数，配置值最小为1。 |

### 二、拨动杆

**kind15：Toggle**

1. 不阻挡kind1、2箭头移动。
2. 箭头移动路径穿过拨动杆，会改变拨动杆的方向，且kind1、2均适用。
3. 每个拨动杆都对应一个或者多个控制器，控制器绑定在物件上。一个关卡可能有多个拨动杆，所以拨动杆和控制器有编号，编号相同表示为同一组的拨动杆和控制器。
4. 拨动杆方向变更后，控制器绑定的物件会立即执行一次绑定物件的行为逻辑如，自身移动，旋转、改变朝向等
5. 一个拨动杆可控制多个物件，触发开关时，同一组控制器绑定的多个物件同时执行自身逻辑。
6. 拨动杆和控制器可放在子区域或者幕布内，并且同一组的拨动杆和控制器可以部分放入子区域或者幕布内。在子区域或者幕布内的拨动杆和控制器只有当子区域或者幕布被开放后，功能才生效。比如拨动杆在子区域或者幕布内，拨动杆是不会受到经过它的箭头影响的；如果是控制器在子区域或者幕布内，和它同组的拨动杆被拨动改变方向，这个控制器也不会产生作用效果。
7. 控制器可绑定的物件类型

#### 绑定物件行为规则

**kind2（翻转箭）：**
- 每改变一次拨动杆方向，绑定了同组控制器的翻转箭改变一次移动朝向；
- 未绑定控制器的翻转箭仍按照每消除一个箭头改变朝向的规则。

**kind4（反射角）：**
- 每改变一次拨动杆方向，绑定了同组控制器的反射角的反射面旋转一定角度。
- 角度通过配置实现，旋转角度为90°的倍数。
- 反射角需要增加配置字段Spin、Spindirection，
  - Spin可配置值为0（默认配置、为0时不旋转），90，180、270。
  - Spindirection可配置为0-顺时针方向（默认配置）、1-逆时针方向。
- 未绑定拨动开关的反射角，默认spin字段配置为0。

**kind7（移动墙）：**
- 绑定了控制器的移动墙，同组拨动杆每改变一次方向，移动墙就按照自身配置的路径及移动格数执行一次移动；
- 未绑定控制器的移动墙，仍按照每消除一个箭头移动一次的规则。

**kind15（收缩障碍）:**
- 绑定了控制器的收缩障碍，同组拨动杆每改变一次方向，收缩障碍就执行一次缩短。但不影响收缩障碍所绑定的管道。

#### 显示

拨动杆单独占一格，样式是比较原始的那种可以左右拨动的小杆子开关。拨动开关对应的控制器是绑定在其他物件上的，是一个中心是红色的小灯。拨动杆和控制器上都有编号，用于标识分组，编号相同的为同一组。拨动杆被拨动改变方向时，同组的控制器灯会闪一下。

#### 参数定义

| 参数 | 说明 |
|------|------|
| groupID | 分组id，用来区分不同分组的拨动杆和控制器。 |

### 三、控制器

**kind16：Controler**

和拨动杆配合使用的控制器，功能作用、可绑定物件、显示要求见kind15的拨动杆。

#### 参数定义

| 参数 | 说明 |
|------|------|
| groupID | 分组id，用来区分不同分组的拨动杆和控制器。 |
